# Sbobinator

Trascrittore audio locale. Zero rete dopo il download iniziale del modello.

## Uso
1. Apri Sbobinator.exe
2. Scegli il modello (Medium o Large)
3. Seleziona il file audio
4. Il .txt con la trascrizione viene salvato accanto al file audio

## Modelli
- **Medium**: ~1.5GB, buono per italiano e dialetti leggeri
- **Large**: ~3GB, migliore per dialetti pesanti e lingue miste

Al primo uso il modello viene scaricato nella cartella `models/` accanto all'exe.
